設定

マイクで拾った音から曲名を特定するのに使います。audd.io で無料トークンを取得できます。

音が小さい・離れた場所で鳴っているときは高めに。動きすぎるときは低めに。

YouTube Music で 👍 した曲を取り込み、好みの分析とおすすめに使います。クライアント ID の作り方は README にあります。ログインは 1 時間ほど有効で、その間に開くと自動で同期します。

YouTube Music などで聴いた曲を Last.fm 経由で取り込みます。Safari 拡張機能「Web Scrobbler」で再生を Last.fm に送り、last.fm/api で無料の API キーを取得してください。アプリを開くたびと、開いている間は 5 分ごとに同期します。

記録はこのブラウザ内（localStorage）だけに保存されます。
